# શાસ્ત્રીજી જીતેન્દ્ર જોષી (જીતુભાઈ જોષી)
### પવિત્ર પૂજા પોર્ટફોલિયો & ડાયનેમિક સામગ્રી CMS (100% શુદ્ધ ગુજરાતી ભાષા)

> ।। શ્રી ગણેશાય નમઃ ।।

## 🚩 વિશેષતાઓ (Key Features)

- **૧૦૦% શુદ્ધ ગુજરાતી ભાષા (Pure Gujarati UI):** સમગ્ર વેબસાઇટ, એડમિન કંટ્રોલ પેનલ અને ડિજિટલ પેમ્ફ્લેટ્સ કોઈ પણ અંગ્રેજી જાર્ગન વગર સંપૂર્ણ ગુજરાતીમાં છે.
- **સોફ્ટ-કોડેડ ડાયનેમિક આર્કિટેક્ચર (Soft-Coded JSON Backend):**
  - [`data/services.json`](data/services.json) — પૂજાઓ, સામગ્રી યાદી અને વિધિ નિયમો.
  - [`data/profile.json`](data/profile.json) — શાસ્ત્રીજીની પ્રોફાઈલ, સંપર્ક નંબર અને ગુપ્ત પિન.
- **સંપૂર્ણ ડાયનેમિક CRUD (Admin Panel):**
  - નવી પૂજા ઉમેરો (Add Service)
  - કોઈપણ પૂજામાં ફેરફાર કરો (Edit Service)
  - જૂની કે અપ્રસ્તુત પૂજા કાઢી નાખો (Delete Service)
  - શાસ્ત્રીજી પ્રોફાઈલ, ફોટો અને સંપર્ક વિગત અપડેટ કરો (Update Profile)
- **સુરક્ષિત એડમિન CMS ([admin.html](admin.html)):**
  - ૪-અંકના ગુપ્ત પિન (`1234`) વડે સુરક્ષિત લૉગિન.
  - મોબાઈલ-ફ્રેન્ડલી ટચ ઇન્ટરફેસ.
- **ઇન્સ્ટન્ટ પેમ્ફ્લેટ એક્સપોર્ટ (Instant Pamphlet Generation):**
  - 🖼️ **PNG ઈમેજ ડાઉનલોડ** (html2canvas)
  - 📄 **A4 પ્રિન્ટ PDF ડાઉનલોડ** (jsPDF)
  - 💬 **વોટ્સએપ શેરિંગ** સીધા યજમાન સાથે
- **ધાર્મિક લાઈટ થીમ (Traditional Dharmik Theme):**
  - Deep Maroon (`#8B1E0F`), Saffron/Kesari (`#D97706`), Turmeric Gold (`#FEF3C7`), Cream (`#FFFDF7`).
- **સંપર્ક સરળતા:**
  - ફક્ત સીધો ફોન કોલ (`99252 64929`) અને WhatsApp ચેટ.

## 🚀 પ્રોજેક્ટ કેવી રીતે ચલાવવો? (How to Run Locally)

### ૧. ડિપેન્ડન્સી ઇન્સ્ટોલ કરો:
```bash
npm install
```

### ૨. લોકલ સર્વર ચાલુ કરો:
```bash
npm start
```
બ્રાઉઝરમાં આ લિંક ખોલો:
- **મુખ્ય વેબસાઇટ:** [http://localhost:3000](http://localhost:3000)
- **એડમિન CMS:** [http://localhost:3000/admin](http://localhost:3000/admin) (મૂળભૂત પિન: `1234`)

## ☁️ Render પર ૧-ક્લિકમાં ડિપ્લોયમેન્ટ (Render Web Service)

પ્રોજેક્ટમાં [`render.yaml`](render.yaml) પહેલેથી તૈયાર છે:
1. [Render.com](https://render.com) પર લૉગિન કરો.
2. **New + > Web Service** સિલેક્ટ કરો.
3. GitHub માંથી આ રિપોઝીટરી `shastriji-jitubhai-joshi-pooja-portfolio` કનેક્ટ કરો.
4. **Deploy** પર ક્લિક કરો! સર્વર ઓટોમેટિક લાઈવ થઈ જશે.

## 📁 પ્રોજેક્ટ ફોલ્ડર માળખું (Project Structure)

```text
├── admin.html          # સ્ટેન્ડઅલોન એડમિન CMS પેનલ (PIN 1234)
├── index.html          # મુખ્ય પવિત્ર પોર્ટફોલિયો પેજ
├── server.js           # એક્સપ્રેસ REST API સર્વર & સ્ટેટિક ફાઈલ હોસ્ટિંગ
├── package.json        # પ્રોજેક્ટ રૂપરેખાંકન & સ્ક્રિપ્ટ્સ
├── render.yaml         # Render 1-ક્લિક ડિપ્લોયમેન્ટ બ્લુપ્રિન્ટ
│
├── data/               # સોફ્ટ-કોડેડ ડેટાબેઝ
│   ├── services.json   # તમામ પૂજાઓ અને સામગ્રીની યાદી
│   └── profile.json    # શાસ્ત્રીજી પ્રોફાઈલ, સંપર્ક અને પિન
│
├── css/
│   ├── design-system.css # ધાર્મિક લાઈટ કલર ટોકન્સ અને વેરીએબલ્સ
│   └── style.css       # મોબાઈલ-ફર્સ્ટ રિસ્પોન્સિવ સ્ટાઇલિંગ
│
├── js/
│   ├── app.js          # મુખ્ય વેબસાઇટ લોજિક, ફિલ્ટર્સ અને સર્ચ
│   ├── db.js           # ડાયનેમિક REST API ક્લાયન્ટ & LocalStorage ફોલબેક
│   ├── admin.js        # એડમિન CMS કંટ્રોલર
│   └── pamphlet-export.js # PNG/PDF/WhatsApp એક્સપોર્ટ એન્જિન
│
└── assets/             # ફોટો, આઇકન અને અપલોડ કરેલ મીડિયા
```
